Next Steps — Genie System

Last updated: 2026-03-16

✅ Completed​

  • Architecture document (docs/design-documents/planning-artifacts/architecture.md) — 8 steps, 7 ADRs + CI/CD
  • Docker Compose — 5 services với pinned versions (genie-api, genie-mysql, genie-redis, genie-qdrant, genie-embedding)
  • Polyrepo setup — 5 submodules (genie-api, genie-chrome-extension, genie-bot, genie-db, genie-admin TBD)
  • genie-db — Prisma schema với 5 tables + scripts
  • GitHub Actions workflows cho genie-api, genie-db, genie-chrome-extension

🔧 Infrastructure Setup (Before First Deploy)​

1. GitHub Secrets — set cho từng repo​

SecretRepo(s)Value
REGISTRY_USERNAMEgenie-api, genie-adminCyberAgent internal registry username
REGISTRY_PASSWORDgenie-api, genie-adminCyberAgent internal registry password
STAGING_DATABASE_URLgenie-dbmysql://user:pass@staging-mysql:3306/genie
PRODUCTION_DATABASE_URLgenie-dbmysql://user:pass@prod-mysql:3306/genie
SHADOW_DATABASE_URLgenie-dbTemp DB for Prisma migrate diff (CI)
BOT_GITHUB_TOKENgenie-dbPAT với write access để auto-tag

2. GitHub Environments​

  • Tạo environment production trong genie-api và genie-chrome-extension repos
  • Set Required reviewers (Teddy hoặc tech lead)
  • Prevents accidental production deploy

3. genie-bot Self-Hosted Runner​

cd genie-system/genie-bot/runners
cp .env.example .env
# Điền GITHUB_TOKEN, RUNNER_NAME, etc.
docker compose up -d

4. Local Dev — First Run​

cd genie-system
cp .env.example .env
# Điền: GENIE_OPENAI_API_KEY, REDIS_PASSWORD, GENIE_OIDC_*, GENIE_CONFLUENCE_*
make dressup
# NOTE: genie-embedding mất 5-10 phút lần đầu (download model ~1.2GB)

5. genie-db — Init Migration​

cd genie-system/genie-db
cp .env.example .env
# Set DATABASE_URL=mysql://user:password@localhost:3306/local_genie
export DATABASE_URL=mysql://user:password@localhost:3306/local_genie
./scripts/migrate.sh dev --name init
./scripts/generate.sh
git add prisma/ migrations/
git commit -m "feat: initial migration"
git tag v0.1.0 && git push origin main --tags
