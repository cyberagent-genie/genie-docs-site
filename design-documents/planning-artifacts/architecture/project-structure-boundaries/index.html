Project Structure & Boundaries

Service Naming Convention​

All services use genie- prefix for consistency. Docker internal DNS aliases follow local-<name>.genie.local pattern.

ServiceDocker service nameInternal DNSPort
Go backendgenie-apilocal-api.genie.local3000
MySQL 8.0genie-mysqllocal-mysql.genie.local3306
Qdrant vector storegenie-qdrantlocal-qdrant.genie.local6333
HuggingFace TEIgenie-embeddinglocal-embedding.genie.local8000
Redisgenie-redislocal-redis.genie.local6379

Polyrepo Git Architecture​

Only services with custom source code get their own git repository. Infrastructure services (pure image + config) live as Docker Compose config in genie-system.

ServiceGit RepoTypeNotes
genie-apicyberagent-genie/genie-apiSubmodule ✅ existingGo backend — frequent code changes
genie-chrome-extensioncyberagent-genie/genie-chrome-extensionSubmodule ✅ existingChrome Extension — frequent code changes
genie-botcyberagent-genie/genie-botSubmodule ✅ existingCI/CD runner config
genie-admincyberagent-genie/genie-adminSubmodule 🆕 newSeparate React admin app — created when Epic 4 begins
genie-dbcyberagent-genie/genie-dbSubmodule 🆕 newPrisma schema + migrations + generated Go client
genie-mysql— no repoDocker Compose config onlyMySQL image + init scripts — no custom code
genie-qdrant— no repoDocker Compose config onlyQdrant image + volume config — no custom code
genie-embedding— no repoDocker Compose config onlyHuggingFace TEI image — zero custom code
genie-redis— no repoDocker Compose config onlyRedis image — no custom code

.gitmodules (final state):

genie-api              → cyberagent-genie/genie-api
genie-chrome-extension → cyberagent-genie/genie-chrome-extension
genie-bot              → cyberagent-genie/genie-bot
genie-db               → cyberagent-genie/genie-db        ← database schema & migrations
genie-admin            → cyberagent-genie/genie-admin     ← add when Epic 4 starts

docker-compose.yml service map:

services:
  genie-api:
    build: { context: genie-api, dockerfile: Dockerfile }
    ports: ["3000:3000"]
    depends_on: [genie-mysql, genie-redis, genie-qdrant, genie-embedding]
    networks: { default: { aliases: [local-api.genie.local] } }

  genie-mysql:
    image: mysql:8.0
    ports: ["3306:3306"]
    volumes: [$PWD/mysql/data/main:/var/lib/mysql]
    networks: { default: { aliases: [local-mysql.genie.local] } }

  genie-qdrant:
    image: qdrant/qdrant:latest
    ports: ["6333:6333"]
    volumes: [qdrant_storage:/qdrant/storage]
    networks: { default: { aliases: [local-qdrant.genie.local] } }

  genie-embedding:
    image: ghcr.io/huggingface/text-embeddings-inference:cpu-latest
    ports: ["8000:80"]
    command: --model-id intfloat/multilingual-e5-large
    networks: { default: { aliases: [local-embedding.genie.local] } }

  genie-redis:
    image: redis:7-alpine
    ports: ["6379:6379"]
    networks: { default: { aliases: [local-redis.genie.local] } }

Data Flow — End to End​

[User selects text in browser]
    ↓
content-script (Shadow DOM React app)
    ↓ chrome.runtime.connect(port: "genie-stream-${actionId}")
service-worker
    ↓ fetch POST https://local-api.genie.local/api/v1/{action}
    ↓   + Authorization: Bearer <access_token>
genie-api
    ↓ auth_middleware → rate_limit_middleware → handler → usecase
    ↓ KnowledgeProvider.Search → genie-qdrant (timeout 1000ms)
    ↓ AIProvider.Stream → OpenAI
    ↓ SSE: metadata event → chunk events → done event
service-worker (relays port messages)
    ↓
content-script feature hook (useTranslate / useSummarize / ...)
    ↓
React UI: ConfidenceBlock renders first → streaming text → done state
