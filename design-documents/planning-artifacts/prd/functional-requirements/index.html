Functional Requirements

1. AI Actions​

  • FR1: User can select text on any web page and trigger translation to a chosen target language
  • FR2: User can trigger summarization of the full current page content
  • FR3: User can receive "Next Steps" suggestions grounded in current page content
  • FR4: User can ask questions in any language and receive answers grounded in Confluence
  • FR5: User can select target language from all LLM-supported languages
  • FR6: User can select AI model from IT-approved allowlist

2. Conversation & Context​

  • FR7: System maintains conversation history scoped to the user's authenticated session
  • FR8: User can ask follow-up questions referencing any response within the current session (minimum last 10 turns retained)
  • FR9: Conversation history is deleted on logout — does not persist beyond SSO session

3. Knowledge Base & Grounding​

  • FR10: System indexes all Confluence spaces the user has permission to access
  • FR11: System runs daily incremental sync of changed Confluence pages
  • FR12: System cross-references AI responses with the organizational Confluence knowledge base
  • FR13: System displays a confidence level indicator for each AI response
  • FR14: System displays source citations (Confluence page links) for grounded information
  • FR15: System distinguishes and notifies when a response is based on general LLM knowledge rather than internal context
  • FR45: System displays a recency indicator for each cited Confluence source, showing the date the source page was last updated

4. Extension & Interface​

  • FR16: User can open/close the AI sidebar on any Chrome page
  • FR17: User can view AI responses streamed in real time
  • FR18: User can view Genie's connection status (online/offline)
  • FR19: Sidebar displays a clear message when genie-api is unreachable
  • FR20: Sidebar displays a clear message when Confluence index is unavailable
  • FR21: User can retry a failed action (timeout, network error) without restarting the sidebar
  • FR22: First-time user is guided through an onboarding flow (SSO connect, capability overview, demo query)

5. Authentication & Access Control​

  • FR23: User authenticates to Genie via company SSO
  • FR24: System restricts access to IT-activated accounts only (pilot: 4 comtors)
  • FR25: Genie session is tied to company identity and expires per SSO policy
  • FR26: User is prompted to re-authenticate when session expires

6. Governance & Security​

  • FR27: All AI requests route through genie-api — no direct extension-to-LLM calls
  • FR28: IT Admin can configure the AI model allowlist
  • FR29: IT Admin can configure which Confluence spaces are indexed
  • FR30: IT Admin can trigger a full Confluence re-index manually
  • FR31: IT Admin can view Confluence index status (running/idle, % complete, last sync time, errors)
  • FR32: System logs request metadata (user, timestamp, action type, model, response time) without logging content — logs used for audit and debugging only, not individual behavioral profiling
  • FR33: Logs are retained 30 days and accessible to IT Admin only
  • FR34: genie-api rejects requests from extension versions below minimum supported version and notifies user to update
  • FR42: System auto-invalidates user sessions after an IT Admin-configurable idle timeout
  • FR43: System enforces model allowlist on every AI request, rejecting any unauthorized model regardless of request source
  • FR44: genie-api applies per-user rate limiting on AI query endpoints

7. Analytics & Feedback​

  • FR35: System tracks session start/end events for Session Duration calculation
  • FR36: System tracks weekly return cohorts for Return Rate calculation
  • FR37: User can submit an in-app NPS survey (1-10 + open question)
  • FR38: User can provide inline accept/reject feedback on each AI response

8. Operations & Reliability​

  • FR39: genie-api exposes a health check endpoint for operational monitoring
  • FR40: Extension and genie-api maintain backward compatibility per semantic versioning contract
  • FR41: Extension displays offline state when genie-api is unreachable — no crash

Capability Contract: 45 FRs across 8 capability areas. Features not listed here do not exist in v1.
